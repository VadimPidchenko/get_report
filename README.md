# Сборка отчётов о тестировании

Локальный инструмент: заполняешь тест-кейсы и баг-репорты в браузере,
получаешь готовый отчёт в DOCX или PDF.

## Установка

Нужны Python 3.10+, Node.js и LibreOffice (последний — только для PDF).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd generator && npm install && cd ..

sudo apt install libreoffice-writer   # если ещё не установлен
```

## Как пользоваться

1. Заполните шапку: проект, дата, адрес трекера.
2. Добавляйте тест-кейсы: название, задачи, предусловие, шаги,
   ожидаемый результат и результат тестирования.
3. Картинки перетаскиваются в поле или выбираются кнопкой.
4. Баг-репорты — на соседней вкладке.
5. «Скачать DOCX» или «Скачать PDF» — отчёт соберётся и загрузится.

Всё введённое сохраняется автоматически.

## Черновики

Боковая панель (кнопка ☰) хранит черновики: обычно по одному на релиз.

- Перезагрузка вкладки возвращает открытый черновик.
- Новый запуск открывает чистый лист и предлагает продолжить прошлый.
- Черновик без кейсов и багов не сохраняется, а опустевший удаляется
  при переходе к другому — с возможностью отменить.

## Структура

```
├── app/                    бэкенд
│   ├── config.py           пути и константы
│   ├── main.py             сборка приложения
│   ├── routes/             HTTP-эндпоинты
│   └── services/           работа с файлами и генератором
├── static/                 интерфейс
│   ├── css/style.css
│   └── js/                 ES-модули, точка входа — app.js
├── generator/              сборка документа на Node
│   ├── generate_report.js  точка входа
│   └── lib/                оформление, блоки, структура отчёта
├── drafts/                 черновики (по JSON на каждый)
├── screenshots/            картинки (по папке на черновик)
└── reports/                готовые отчёты (по папке на черновик)
```

## Как устроен отчёт

Каждый тест-кейс занимает отдельную страницу, поля выводятся в едином
порядке — незаполненные показываются с прочерком. Готовые файлы кешируются:
пока черновик не изменился, повторное скачивание не запускает сборку заново.

## Если что-то не работает

- **PDF не создаётся** — проверьте `soffice --version`. Без LibreOffice
  доступен только DOCX.
- **В отчёте «картинка не найдена»** — файл удалили из `screenshots/{id}/`
  вручную; загрузите заново.
- **Картинки весят слишком много** — скриншотилки иногда сохраняют BMP
  под расширением `.png`. При загрузке такие файлы автоматически
  пересохраняются в настоящий PNG без потери качества.
